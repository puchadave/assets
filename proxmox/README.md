# webOwie Proxmox Branding

Direkte Installation aus dem zentralen Asset-Repository:

```bash
curl -fsSL https://raw.githubusercontent.com/puchadave/assets/main/proxmox/install-webowie-proxmox-branding.sh | bash
```

Restore:

```bash
/usr/local/sbin/webowie-pve-branding --restore
```

Alle Logos und PVE-Bilder werden aus `puchadave/assets` bezogen.
